# Cartola FC Pipeline

Pipeline para análise de dados do Cartola FC usando GitHub Actions.

## Arquivos

- `coleta_dados_cartola.py` - Coleta dados da API do Cartola
- `calcular_normalizacao_posicao.py` - Normalização por posição
- `calcular_teto_piso.py` - Cálculo de teto/piso de score
- `recalibrar_mando.py` - Recalibração do ajuste de mando
- `validar_rodada.py` - Validação pós-rodada
- `pipeline_semanal.py` - Orquestrador do pipeline
